Ongoing · M.Tech research

Decision-aware memory for agentic context engineering (ACE)

ACE keeps an evolving context made of bullets and merges near-duplicates to stay compact. I study when that merge is unsafe: two bullets can read almost the same yet call for different decisions.

Identify near-duplicate bullets that require different decisions.
Measure decision-divergent merges in ACE.
Prevent unsafe merges with a decision-aware check.
Evaluate the trade-off between memory compression and decision preservation.

Planned evaluation: the original ACE system against a decision-aware version, on memory compression, decision preservation, unsafe merge rate, and computational overhead.
